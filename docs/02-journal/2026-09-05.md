## Appris
- I2C : Protocole de communication série qui utilise 2 fils : SDA pour les données et SCL pour l’horloge
- Pin digitale : Pin qui ne prend que 2 états : 0V ou 3.3V/5V
- Pin analogique : Pin qui peut lire une valeur continue entre 0V et 3.3V/5V
- Le DHT22 permet de mesurer 2 paramètres : Température et Humidité [paramètre : 2 mesures]
- Pour faire fonctionner un ESP32, il faut d’abord le flasher depuis Thonny puis envoyer le code d’application
